# AI 역량평가 연습

첨부된 평가 화면을 참고한 한국어 객관식 연습 사이트. 외부 런타임 의존성, API 키, 백엔드가 필요 없는 정적 HTML/CSS/JavaScript입니다.

## 로컬 실행

```sh
cd /Users/a123/workspace/ai-assessment-practice
npm start
```

http://127.0.0.1:4173 에서 실행합니다. `npm test`로 생성 문항의 정답, 자료 계산, 채점 규칙을 검증합니다.

## 메뉴 및 동작

- AI 활용평가: 가상 FAI 정책·팀 현황·명부를 바탕으로 4개 객관식 문제, 자료 뷰어, 10회 규칙 기반 힌트.
- AI 지식평가: 기본 개념, 모달리티, 프롬프트, 공정성, 데이터 관리, 결과 검증, RAG, 환각, XAI, 가명 처리 등 10개 객관식 문제. O/X 포함.
- 평가 시작·페이지 새로고침 후 재시작·채점 후 새 문제 생성 시 상황, 수치 및 보기 순서 재생성. 현재 평가 내 문제 이동은 동일 문항과 답안을 유지합니다.
- 답안 선택, 이전/다음, 문제 번호 이동, 다시 풀 표시, 초기화, 미응답 확인, 100점 환산, 문제별 정답·해설.

문제 생성은 검토된 템플릿을 브라우저에서 조합하는 방식입니다. 매번 새로운 주제를 LLM으로 무한 생성하는 기능은 아닙니다. 노출되는 자료는 PDF를 별도 다운로드하는 방식이 아니라 HTML로 렌더링한 가상 문서입니다. 답안은 현재 메모리에만 보관하며 새로고침하면 초기화됩니다.

## GitHub Pages

`dist/`가 배포 대상이며 모든 리소스 경로는 상대 경로입니다. 새 저장소의 `main`에 코드를 푸시하고 Settings → Pages → Source를 GitHub Actions로 설정하면 `.github/workflows/pages.yml`이 테스트 후 정적 파일을 배포합니다. 공개 배포에는 저장소와 소스 코드도 공개될 수 있습니다. 정답도 브라우저 소스에 포함되므로 연습용으로만 사용하세요.
