# AI 역량평가 연습

첨부된 평가 화면을 참고한 한국어 객관식 연습 사이트. 외부 런타임 의존성, API 키, 백엔드가 필요 없는 정적 HTML/CSS/JavaScript입니다.

## 로컬 실행

```sh
cd /Users/a123/workspace/ai-assessment-practice
npm start
```

http://127.0.0.1:4173 에서 실행합니다. `npm test`로 생성 문항의 정답, 자료 계산, 채점 규칙을 검증합니다.

## 메뉴 및 동작

- AX 직무역량평가: KT 2026년 대졸신입 B2B컨설팅&세일즈 공고만 참고. 기본 직무역량 5문제 + AX 문제해결 5문제. 두 영역의 정답 수와 점수를 별도로 표시합니다. 자기소개서와 지원자 개인정보는 사용하지 않습니다.
- AI 활용평가: 간식 설문, 구독 최적화, 상품 규정, 고객 의견, B2B 캠페인, 협력사 구매는 각 4문제. 교육 효과성과 개선 전략은 8문제.
- AI 지식평가: 18개 문항 유형 중 10개를 선정합니다.
- 전체 81개 문항 유형에서 메뉴별 세트를 선택하고, 수량·예산·비율·문서 조건·보기 등을 생성합니다. 신규 세트에서는 질문 주제와 자료가 함께 달라집니다. 모든 문항은 객관식이며 일부 O/X를 포함합니다.
- 자료 뷰어는 가상의 표·정책·RFP·회의 기록을 HTML로 렌더링합니다. 파일명에 PDF를 표시하지만 실제 PDF 다운로드 파일은 아닙니다.
- 어시스트는 외부 LLM이 아닌 현재 문항의 검토된 힌트를 제공하는 규칙 기반 기능입니다. 자료가 있는 평가에서 세트당 10회 사용 가능합니다.
- 답안 선택, 문제 이동, 다시 풀 표시, 초기화, 미응답 확인, 100점 환산, 문제별 정답·해설을 제공합니다.

평가 시작과 채점 후 새 문제 생성은 자료와 문제를 새로 구성합니다. 같은 평가 안의 문제 이동은 답안과 자료를 유지합니다. 새로고침하면 현재 탭에 저장된 평가·답안·메모·시간·대화를 복원합니다. 템플릿 조합으로 생성하므로 특정 개념이나 문항 유형은 반복될 수 있으며 무한히 새로운 LLM 문항을 생성하는 기능은 아닙니다.

## GitHub Pages

`dist/`가 배포 대상이며 모든 리소스 경로는 상대 경로입니다. 새 저장소의 `main`에 코드를 푸시하고 Settings → Pages → Source를 GitHub Actions로 설정하면 `.github/workflows/pages.yml`이 테스트 후 정적 파일을 배포합니다. 공개 배포에는 저장소와 소스 코드도 공개될 수 있습니다. 정답도 브라우저 소스에 포함되므로 연습용으로만 사용하세요.

## 가이드에 맞춘 연습 흐름

1. 메뉴 선택 → 시작 안내와 연습 시간 선택.
2. 사전 체험(별도 2문항, 시간 제한·채점 없음) 또는 본 연습 시작.
3. 보기 선택 시 답안 저장, 파란 체크 표시. 문제 이동·수정과 노란 깃발 표시 가능.
4. 문제별 메모와 내 답안 현황. 종료 전 미응답을 검토하고 해당 문제로 이동.
5. 최종 제출 후 답안 수정 잠금과 정답·해설 제공. 제한 시간 종료 시 현재 답안을 자동 제출.

어시스트는 공통 지문/문제 번호 선택, 자료별 AI 질문에 추가, 질문 1,000자, 30초 재전송 대기, 세트당 10회, 최근 10개 대화 쌍 표시를 지원합니다. 질문 전송 후 첨부를 해제하므로 필요하면 다시 첨부해야 합니다. 실제 LLM 및 토크나이저는 없으며, 20,000토큰 제한을 모델 기준으로 검사하지 않습니다. 파일 자료는 작은 가상 문서만 제공합니다.

본 연습의 지문·보기·문서 뷰어에서 텍스트 선택/복사를 제한합니다. 이는 UI 조작 연습이며 실제 시험의 보안·감독 시스템이 아닙니다. 웹캠·화면공유·모니토는 요청하지 않습니다. 기존의 객관식만 연습하는 범위와 dark 테마를 유지합니다.

저장은 탭 단위 sessionStorage를 사용하며 서버에 업로드하지 않습니다. 브라우저에서 저장이 차단되면 화면에 자동 저장 불가를 표시합니다. 제한 시간은 종료 시각 기준으로 계산하여 새로고침이나 메뉴 이동으로 시간이 초기화되지 않습니다.


AI 활용평가와 AX 평가의 어시스트 패널은 데스크톱에서 기본으로 표시됩니다. 패널을 닫아도 지문·각 문제 옆·하단의 AI 어시스트 버튼으로 다시 열 수 있습니다. 모바일에서는 문제를 가리지 않도록 패널을 접고 하단 버튼으로 여는 방식을 사용합니다. 이전 버전에서 저장된 초기 닫힘 상태는 첫 복원 시 정상 표시 상태로 전환합니다.

배포 자산에는 버전 쿼리를 사용해 이전 JavaScript·CSS 캐시가 수정 화면을 가리지 않게 합니다. 이후 배포 시 index.html과 JS import의 버전 값을 함께 갱신하세요.
